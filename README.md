# ShopCore

Ядро интернет-магазина на Python с использованием ООП.

## Описание проекта

Проект разработан в рамках курса "Объектно-ориентированное программирование" и представляет собой основу для интернет-магазина.

## Реализованная функциональность

- Класс `Product` для представления товаров
- Класс `Category` для управления категориями
- Автоматический подсчёт количества категорий и товаров
- Покрытие тестами > 75%

## Установка

```bash
poetry install

```

## Запуск
```bash
poetry run python main.py
```
## Тестирование
```bash
poetry run pytest tests/ --cov=src --cov-report=html
```
## Структура проекта
```bash
shopcore/

├── tests/            # Тесты
```
