# ShopCore

Ядро интернет-магазина на Python с использованием ООП.

## Описание проекта

Проект разработан в рамках курса "Объектно-ориентированное программирование" и представляет собой основу для интернет-магазина.

### Домашнее задание 14.1 (Введение в ООП)
- Класс `Product` с атрибутами: name, description, price, quantity
- Класс `Category` с атрибутами: name, description, products
- Атрибуты класса `Category`: `category_count` и `product_count` для автоматического подсчета
- Тесты для проверки инициализации объектов и подсчета категорий/товаров

### Домашнее задание 14.2 (Режимы доступа)
- Атрибут `products` класса `Category` сделан приватным (`__products`)
- Добавлен метод `add_product()` для безопасного добавления товаров
- Реализован геттер `@property` для атрибута `products` (возвращает строку)
- Атрибут `price` класса `Product` сделан приватным (`__price`)
- Реализованы геттер и сеттер для атрибута `price` с валидацией (защита от отрицательной цены)
- Добавлен класс-метод `new_product()` для создания продукта из словаря
- Покрытие тестами > 75%
- Код проверен линтером Flake8
