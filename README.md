# ShopCore

Ядро интернет-магазина на Python с использованием ООП.

![ShopCore Logo](logo.svg)

## Назначение

ShopCore — доменное ядро интернет-магазина: товары, категории, учёт цен и остатков.
Проект развивается поэтапно: каждая задача — в отдельной ветке GitFlow, слияние в `main` только через pull request.

## Доменная модель

### Product
Товар: название, описание, цена, количество.
- Инкапсуляция: цена и количество защищены, изменение — через сеттеры с валидацией.
- Магические методы: `__str__`, `__repr__`, `__add__` (арифметика стоимости товаров).

### Category
Категория, хранящая товары.
- Добавление товаров и агрегация по коллекции.
- Счётчики категорий и общего числа товаров на уровне класса.

### Smartphone / LawnGrass
Подклассы `Product` (наследование):
- `Smartphone` — модель, память, цвет;
- `LawnGrass` — страна происхождения, срок всхожести, цвет;
- переопределение `__init__` через `super()` и расширение поведения базового класса.

## Стек и инструменты

- Python 3.10+
- pytest — юнит-тесты (покрытие > 75%)
- Poetry — управление зависимостями
- Git / GitFlow — ветки `hw/*`, слияние через PR
- flake8 — контроль стиля кода

## Запуск

```bash
poetry install
python main.py
```

## Тесты

```bash
poetry run pytest
```

## Правила разработки

- Каждая задача — в ветке hw/<номер>.
- Слияние в main — только через pull request.

Учебный проект (модуль ООП): инкапсуляция, наследование, магические методы, тестирование.
